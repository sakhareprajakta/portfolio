# Prajakta Sakhare - Web Developer Portfolio

A responsive, high-performance web developer portfolio built with React.js, modern CSS animations, and interactive components.

## 🚀 Features

- **Hero & Profile Showcase:** Professional introduction with dynamic role animation, key technical achievements, and modern avatar presentation.
- **About Me:** Highlights 2+ years of production experience as a Web Developer at Vetrina Healthcare Pvt. Ltd., full-stack engineering background, and core technical strengths.
- **Skills Matrix:** Categorized technical expertise across Frontend (React.js, Next.js, Redux Toolkit), Backend (Node.js, Express.js, REST APIs, JWT/RBAC), Databases (MongoDB, MySQL), Cloud & DevOps (AWS, VPS, Vercel, Git/GitHub), and AI-assisted workflows (Gemini AI API).
- **Featured Projects:**
  - **AI-Based Task Management System:** Smart task prioritization engine, visual task board, JWT-secured auth, real-time analytics dashboard, and Gemini AI API integration with live demo link.
  - **Advanced Job Application Automation for Workday:** Manifest V3 Chrome Extension browser automation with dynamic field-detection and candidate profile management.
- **Certifications & Accreditations:** High-resolution verified credentials and certificates with interactive full-screen preview modal and PDF access.
- **Contact & Direct Messaging:** Working contact form integration with EmailJS and instant email client fallback.

## 🛠️ Tech Stack

- **Frontend:** React 19, JavaScript (ES6+), HTML5, CSS3, Modern Animations
- **Email Service:** @emailjs/browser
- **Typography:** Plus Jakarta Sans, JetBrains Mono
- **Deployment:** Vercel / GitHub Pages

## 📦 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/sakhareprajakta/portfolio.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run locally:
   ```bash
   npm start
   ```

4. Build for production:
   ```bash
   npm run build
   ```
